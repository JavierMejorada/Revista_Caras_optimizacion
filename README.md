# 🌐 Proyecto: Landing Page - Code Together  

💻 Desarrollado con **React + TypeScript** | Estilos globales y componentes reutilizables.  

---

## 📖 Descripción  
Este proyecto es una **Landing Page moderna y responsiva**, creada con **React** y **TypeScript**.  
El objetivo principal es demostrar buenas prácticas de arquitectura en proyectos grandes:  
- Estructura modular de componentes.  
- Estilos globales para consistencia visual.  
- Separación clara entre secciones (Header, Formulario, Testimonios, Footer, etc.).  

La página incluye un **formulario de suscripción**, secciones destacadas, testimonios de usuarios y un pie de página con enlaces.  

---

## 🚀 Tecnologías utilizadas
- ⚛️ **React** (con Vite o CRA).  
- 📘 **TypeScript** para tipado seguro y mantenible.  
- 🎨 **Styled Components / GlobalStyles** para estilos consistentes.  
- 🔧 **Git & GitHub** para control de versiones.  

---

## ✨ Características
- 🧩 Arquitectura de **componentes reutilizables**.  
- 📱 **Responsive Design** para móviles, tablets y desktop.  
- 📩 Formulario de suscripción funcional.  
- ⭐ Sección de testimonios para mejorar credibilidad.  
- 🎯 Código limpio, escalable y fácil de mantener.
